# Design Sesh Portfolio Builder

10 sequential skills for building a portfolio that reflects its owner's personality, using Claude and existing assets. No image generation required.

Read [START-HERE.md](START-HERE.md) for instructions and copy-and-paste prompts. Each skill is a standalone `SKILL.md` in [skills/](skills/).

## Portfolio sequence

1. **01** Analyze visual references.
2. **02** Discover personality, voice and goals.
3. **03** Choose a design direction.
4. **08** Analyze and organize project files; repeat for each project.
5. **04** Plan the site story and personal touches.
6. **05** Build the site foundation.
7. **09** Build the Projects page and any agreed case studies.
8. **10** Build the About page.
9. **06** Review personality, responsiveness and usability.
10. **07** Prepare the owner handoff.

The folder numbers identify skills; follow the sequence above for a portfolio. For a general personal site, use 01–07.

## Use with Claude

Download or clone this repository into your website workspace. Ask Claude to read the relevant `SKILL.md` and carry out its instructions, using previous outputs in `design-notes/`. If your environment supports skill loading, use its supported mechanism. Image inspection and file editing are needed for the full workflow; browser access improves verification.

Original files stay intact by default. Personal details come from the owner rather than guesses from a mood board. Project claims are grounded in evidence. Building locally and publishing are separate actions.

These instructions have basic structural checks but have not been behavior-tested inside Claude.
